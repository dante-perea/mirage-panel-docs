---
title: "Qué contiene esta sección"
description: "Respaldos de la base de datos del servidor seleccionado."
---

**Copias de seguridad** administra los respaldos de la base de datos del servidor seleccionado. No es una descarga del cliente Android o Windows ni una exportación del código fuente.

La tabla muestra fecha, tamaño, duración y estado de cada copia. Comprobá que el respaldo que querés usar tenga estado **OK**. El tamaño comprimido de la copia puede ser menor que el tamaño de la base.

La pantalla actual ofrece **Copia ahora** y **Restaurar**. No muestra un botón de descarga del respaldo. Si necesitás exportarlo, consultá soporte; no uses un enlace de descarga de clientes para ese fin.
