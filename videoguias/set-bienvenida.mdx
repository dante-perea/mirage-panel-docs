Desactivar el **Set de bienvenida** evita nuevas entregas. **No elimina los objetos que los personajes ya recibieron.**

## Pasos del video

1. Desde **Inicio**, tocá **Ajustes**.
2. Abrí **Funciones adicionales**.
3. En **Buscar una función**, escribí **Set de bienvenida**. Dejá el filtro en **Todas**.
4. Abrí **Detalles** e identificá la fila cuyo nombre en el servidor es **Add 48h starter rental set and weapon**.
5. Apagá el interruptor de esa fila.
6. Esperá **Set de bienvenida: desactivado. Cambio guardado.** y comprobá que la fila diga **Desactivado**.

Puede haber otra fila llamada Set de bienvenida, con el nombre **Activate 24h starter rental set grant**. No confundas esa actualización con la función que entrega el equipamiento a cada personaje nuevo.

El interruptor guarda automáticamente; no hace falta reiniciar el servidor. Para comprobar nuevas entregas, usá un personaje creado después del cambio.
