## Miralo en la captura

<Frame>
![Overview de Tiendas para verificar la grilla tras editar](/images/shops/01-overview.png)
</Frame>

En esta pantalla fijate en la grilla del mercader seleccionado: es lo que deberías contrastar después contra el NPC in-game.

## Qué hacer

<Steps>
<Step>
Sacá una referencia de la grilla actual (screenshot).
</Step>
<Step>
Editá (mover / x / añadir) y cerrá con **Listo** si usaste el diálogo.
</Step>
<Step>
Entrá al juego, hablá con ese NPC y confirmá el inventario.
</Step>
<Step>
Si no se ve in-game: recargá el panel; si sigue, verificá si el game server cachea shops.
</Step>
</Steps>

## Si ves esto…

| Problema | Qué probar |
|----------|------------|
| No ves **Añadir objeto** | Seleccioná un mercader de la lista |
| Cambios no se ven in-game | Recargá el panel; puede hacer falta reload del game server |
| Diálogo sin Cancel | **Listo** cierra; recargar sin colocar = no guarda |
