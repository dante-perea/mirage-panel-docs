---
title: ¿Por qué no veo los cambios in-game?
description: Verificación y posibles caches
---

Flujo recomendado tras editar una tienda:

1. Screenshot de la grilla actual.
2. Editá (mover / x / añadir).
3. **Listo**.
4. Entrá al juego, hablá con ese NPC y confirmá el inventario.
5. Si no se ve in-game: recargá el panel; si sigue, verificá si el game server cachea shops.

![Tiendas overview](/images/shops/01-overview.png)

## Resolución de problemas

| Problema | Qué probar |
|----------|------------|
| No ves **Añadir objeto** | Seleccioná un mercader de la lista |
| Cambios no se ven in-game | Recargá el panel; puede hacer falta reload del game server |
| Diálogo sin Cancel | **Listo** cierra; recargar sin colocar = no guarda |
