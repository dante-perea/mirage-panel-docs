---
title: ¿Cómo añado un objeto a una tienda?
description: Diálogo Añadir objeto
---

<Steps>
<Step>
Con el mercader seleccionado, clic en **Añadir objeto**.
</Step>
<Step>
Se abre el diálogo (queda abierto para cargar varios seguidos).
</Step>
<Step>
Completá selector de item, nivel, cantidad y opciones (Luck / Skill / Excellent).
</Step>
<Step>
Clic en un hueco vacío **o** **Autocolocar en el primer hueco libre**.
</Step>
<Step>
Repetí si hace falta; cuando termines, **Listo**.
</Step>
</Steps>

![Diálogo Añadir objeto](/images/shops/03-add-item.png)

| Campo | Qué es |
|-------|--------|
| **Selector de item** | Combobox |
| **Tamaño** | Verde cabe, rojo bloqueado |
| **Nivel del objeto** | Default `0` |
| **Cantidad** | Default `1` |
| **Luck / Skill / Excellent** | Checkboxes |
| **Autocolocar…** | Primer slot que entre |
| **Listo** | Cierra el diálogo |

<Warning>
Si cerrás recargando la página **sin** Listo / sin colocar, no se guarda.
</Warning>
