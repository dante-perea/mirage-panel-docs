description: "Cómo detener la entrega de equipamiento a personajes nuevos desde Ajustes del juego y Plugins."
---

El **Set de bienvenida** entrega equipamiento de alquiler a los personajes nuevos. Se puede desactivar desde el panel. El cambio evita nuevas entregas; **no elimina los objetos que otros personajes ya recibieron**.

## Desactivar nuevas entregas

1. Entrá a [tu panel](https://jugarmu.com/panel) y elegí el servidor correcto.
2. Abrí **Ajustes del juego → Plugins**.
3. En **Buscar una función**, escribí **Set de bienvenida**. Dejá **Estado** en **Todos** para encontrarlo aunque esté desactivado.
4. En **Bienvenida y progresión**, abrí **Detalles** y buscá la fila cuyo nombre en el servidor es **Add 48h starter rental set and weapon**. Apagá el interruptor de esa fila. Puede haber otra fila con el mismo título: **Activate 24h starter rental set grant** es una actualización y no es la función que entrega el equipo al crear cada personaje.
5. Esperá la confirmación **Set de bienvenida: desactivado. Cambio guardado.** y verificá que la fila muestre **Desactivado**.

El interruptor guarda automáticamente. No hace falta pulsar otro botón de guardar ni reiniciar el servidor. Si aparece un error o no se confirma el cambio, recargá la página y comprobá el estado antes de repetirlo.

## Qué pasa con los personajes existentes

Desactivar esta función no retira los regalos ya entregados ni cambia sus condiciones de alquiler. No confundas el plugin que entrega el set con las funciones que retiran alquileres vencidos.

Para verificar el resultado, creá un personaje de prueba después de confirmar el guardado. Un personaje creado antes conserva el equipamiento que ya había recibido.

## Si no encontrás la función

Limpiá la búsqueda, seleccioná **Todos** y comprobá que elegiste el servidor correcto. Si sigue sin aparecer, consultá soporte indicando la versión y una captura de Plugins. Que una función no aparezca en una instancia no significa que no exista en el panel.
